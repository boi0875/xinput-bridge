XInput Bridge

Xbox-protocol USB controllers for Chrome on macOS

This browser has no WebUSB support, so the bridge can't run. Use Google Chrome 118 or newer.

Set up in three steps

  1. Plug in your controller or its USB receiver, and switch the controller on.
  2. Click Pair a controller, pick it in Chrome's list and click Connect. You only do this once.
  3. Open your game (GeForce NOW, Xbox Cloud Gaming, a browser game) and press any button. Already-open tabs need a reload first.

Controllers

Settings

Ignores small stick movement around the center, so a worn stick doesn't drift. Most games add their own, so keep it small.

Lets sites that use the Gamepad vibration API shake the controller.

Shows a short "Player 1 connected" notice in the corner of the page.

Sites pick button labels and layouts from the controller's name. An Xbox controller is what they handle best.

Turned off on

Sites where the bridge stays out of the way. Turn a site off or back on from the toolbar button.

Troubleshooting
My controller isn't in Chrome's list
Check for a mode switch or button combo and pick X-input (often "X" or PC mode). If it's a plain HID gamepad, Chrome already supports it and you don't need this extension. Try Show all USB devices to pair a controller that doesn't advertise the Xbox interface.
"Another tab, extension or app is using this controller"
Only one program can talk to the controller at a time. Remove older controller extensions (for example an earlier GFN Controller Bridge), close pages that use it over WebUSB, then click Retry.
It works here but not in my game
Reload the game's tab, then press a button: like Chrome, the bridge only shows controllers to a page after a button press. Check that the site isn't turned off in the toolbar button.
Rumble does nothing
The site has to use the Gamepad vibration API. Use Test rumble above to check the controller itself.
Windows and Linux
You don't need this there: the system driver already supports these controllers, and because it holds the device, the extension can't open it.

Raw USB reports

The bytes each controller sends, for debugging or for adding support for a new controller. Press buttons one at a time and include the output in a bug report.
